# Foodie & Friend Cuisine

The FFC website is a standard Next.js App Router application for Vercel.

## Requirements

- Node.js 20.9 or newer

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

## Vercel

Use Vercel's **Next.js** framework preset with the repository root as the root directory. The default install and build commands are sufficient.

No environment variables are required for the website. Optionally set `NEXT_PUBLIC_SITE_URL` to the canonical production URL for absolute social metadata when using a custom domain.
